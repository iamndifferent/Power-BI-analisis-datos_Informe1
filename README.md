# Power-BI-analisis-datos_Informe1
Este proyecto utiliza Power BI para transformar datos en información visual que facilite la exploración de resultados y la toma de decisiones. El informe reúne visualizaciones y elementos interactivos en un dashboard con la Venta a Nivel Global dentro de la Industria de los Videojuegos, con el objetivo de presentar la información de forma clara y accesible.
Objetivos
- Explorar y comprender el conjunto de datos utilizado.
- Organizar la información para facilitar su lectura y comparación.
- Diseñar visualizaciones que ayuden a identificar tendencias, diferencias y patrones relevantes.
- Presentar los resultados mediante un informe visual e interactivo.
Herramientas y tecnologías
- Microsoft Power BI Desktop — creación del informe y visualizaciones.
- Power Query — preparación y transformación de datos, si se utilizó.
- DAX — medidas y cálculos, si se utilizaron.
Metodología
1. Revisión de datos: identificación de las tablas, campos y tipos de datos disponibles.
2. Preparación: limpieza y transformación de los datos, cuando corresponda.
3. Análisis: definición de métricas y comparaciones relevantes para el objetivo del proyecto de Ventas.
4. Visualización: selección de gráficos, indicadores y filtros para comunicar los resultados.
5. Validación: revisión de los valores y de la coherencia de las visualizaciones.
Estado del proyecto
Proyecto de portafolio. La documentación y las visualizaciones se pueden ampliar a medida que se incorporen mejoras.
